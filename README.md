📘 algorithm_APP — 基本アルゴリズム学習アプリ
🎯 目的（Purpose）
このアプリは 基本アルゴリズムの習得を目的として設計されています。
ユーザーが 「アルゴリズムの動きを視覚的に理解する」ことを最優先にしています。

🧩 構造（Structure）
アプリは以下の最小構造で動作します：

入力（Input） — ユーザー操作（ボタン、値入力など）

処理（Logic） —

当たり判定

キュー

スタック

バイナリサーチ

マージソート

出力（Output） — 画面アニメーション・結果表示

状態管理（State） — 必要最小限の内部状態を保持

UI / UX — シンプルなボタン操作で理解を妨げない構造

構造は 教育向けに最適化されており、
誰でも理解できる「アルゴリズムの本質」を見える形にしています。

🛠 使用技術（Tech Stack）
言語：C++ / C

フレームワーク：DXライブラリ

開発思想：最小構造・高速描画・教育向けUI

📦 機能（Features）
キュー可視化機能  
FIFO の動きをアニメーションで理解できる

スタック可視化機能  
LIFO の構造を視覚的に表示

バイナリサーチ機能  
探索範囲が縮む様子を段階的に表示

マージソート機能  
分割 → 結合の流れをアニメーション化

当たり判定（Collision Detection）機能  
ゲーム開発の基礎となる衝突判定を視覚的に理解

必要に応じて機能追加が可能な 拡張性の高い構造になっています。

🚧 例外・エラー処理（Exceptions）
アプリでは以下の例外を局所化して処理しています：

入力が空の場合

範囲外の値が入力された場合

アルゴリズム実行中の不正操作

例外処理は 構造に影響しないよう分離されており、
学習体験を妨げない設計です。

🔄 改善ポイント（Improvements）
今後の改善予定：

アニメーションの録画・画像保存機能

PDF 形式でのアルゴリズム解説書出力

新しいアルゴリズム（Dijkstra、A*、BFS/DFS など）の追加

UI のテーマ切り替え（ライト / ダーク）

改善はすべて 既存構造を壊さず拡張できる形で設計しています。
